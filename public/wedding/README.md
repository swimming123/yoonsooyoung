# 웨딩플래너 (1단계)

기존 웨딩플래너의 HTML·JS·CSS 파일을 이 폴더에 그대로 넣으세요. 시작 파일은 `index.html` 이어야 합니다.

- 배포 후 주소: `https://swimming123.github.io/yoonsooyoung/wedding/index.html`
- 사이트의 `/wedding` 화면이 이 파일을 iframe 으로 보여줍니다.
- 기존 코드의 Firebase 설정이 사이트와 같은 Firebase 프로젝트를 가리키면 로그인 상태가 공유됩니다.
- Firebase 설정값은 원래 공개되는 값이라 이 폴더에 있어도 괜찮지만, 서비스 계정 키(JSON)는 절대 넣지 마세요.

2단계에서 이 파일들을 `src/features/wedding/` 의 Vue 컴포넌트로 옮깁니다.
