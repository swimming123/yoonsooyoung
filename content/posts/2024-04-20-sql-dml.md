DML은 테이블에 들어 있는 데이터를 조회(SELECT)하고, 넣고(INSERT), 고치고(UPDATE), 지우는(DELETE) 명령어다.

## SELECT: 데이터 조회

```sql
SELECT [ALL | DISTINCT] 속성이름(들)
FROM 테이블이름(들)
[WHERE 조건(들)]
[GROUP BY 속성이름]
[HAVING 검색조건(들)]
[ORDER BY 속성이름 [ASC | DESC]];
```

**처리 순서**: FROM → ON → JOIN → WHERE → GROUP BY → WITH CUBE / WITH ROLLUP → HAVING → SELECT → DISTINCT → ORDER BY → TOP

### WHERE 절에서 쓰는 연산자

| 종류 | 연산자 |
| --- | --- |
| 비교 | `=`, `<>`, `!=`, `<`, `<=`, `>`, `>=` |
| 범위 | `속성 BETWEEN 최솟값 AND 최댓값` |
| 집합 | `IN ( )`, `NOT IN ( )` |
| 패턴 | `LIKE` |
| NULL | `IS NULL`, `IS NOT NULL` |
| 복합 조건 | `AND`, `OR`, `NOT` |

### 와일드카드 문자

| 문자 | 뜻 |
| --- | --- |
| `+` | 문자열 연결 (SQL Server) |
| `%` | 0개 이상의 문자열과 일치 |
| `_` | 특정 위치의 문자 1개와 일치 |
| `[ ]` | 괄호 안의 문자 1개와 일치 (SQL Server) |
| `[^ ]` | 괄호 안에 없는 문자 1개와 일치 (SQL Server) |

### 집계 함수

```sql
SUM([ALL | DISTINCT] 속성이름)
AVG([ALL | DISTINCT] 속성이름)
COUNT({[ALL | DISTINCT] 속성이름 | *})
MAX([ALL | DISTINCT] 속성이름)
MIN([ALL | DISTINCT] 속성이름)
```

- 연산할 때 NULL 처리에 주의해야 한다.
- GROUP BY를 쓰면 SELECT에는 GROUP BY에 쓴 속성과 집계 함수만 올 수 있다.

### 부속 질의(서브쿼리)

| 종류 | 위치 | 설명 |
| --- | --- | --- |
| 스칼라 부속 질의 | SELECT 절 | 단일 행, 단일 열의 값 하나를 돌려준다. |
| 인라인 뷰 | FROM 절 | 결과를 뷰처럼 돌려준다. 조인 전에 필요한 데이터만 추려서 성능 손실을 줄일 수 있다. |
| 중첩 질의 | WHERE 절 | 조건 연산자와 함께 써서 결과를 한정한다. |

## INSERT: 데이터 넣기

**1. 컬럼 이름을 적는 방법**

컬럼 이름과 값의 순서가 맞아야 한다. 원하는 컬럼에만 값을 넣을 수 있다.

```sql
INSERT INTO 테이블이름 (컬럼1, 컬럼2, ...)
VALUES (컬럼1값, 컬럼2값, ...);
```

**2. 모든 컬럼에 넣는 방법**

컬럼 이름 없이 값만 쓴다. 테이블의 컬럼 순서와 값의 순서가 같아야 하고, NOT NULL 컬럼 값은 생략할 수 없다.

```sql
INSERT INTO 테이블이름
VALUES (모든 컬럼의 값을 순서대로);
```

## UPDATE: 데이터 고치기

```sql
UPDATE 테이블이름
SET 컬럼 = '값' [, 컬럼 = '값', ...]
[WHERE 기준컬럼 = '값'];
```

## DELETE: 데이터 지우기

```sql
DELETE [FROM] 테이블이름
WHERE 조건;
```
