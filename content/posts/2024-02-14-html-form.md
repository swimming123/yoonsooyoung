## method 속성: GET과 POST

기본 전송 방식은 GET이지만, 중요한 데이터를 보낼 때는 POST를 쓴다.

| | GET (기본값) | POST |
| --- | --- | --- |
| 전달 방식 | 주소(URL)에 데이터를 붙여서 전달 | 주소를 바꾸지 않고 요청 본문에 담아 전달 |
| 크기 | 제한 있음 | 제한 없음, 많은 데이터 전송 가능 |
| 보안 | URL에 그대로 보여서 보안이 필요 없는 데이터에 | URL에 보이지 않아 상대적으로 안전. 로그인 같은 인증 처리에 |
| 특징 | 가볍고, 자주·빈번하게, 적은 양을 보낼 때 | 무겁지만 안정적 |

## action 속성

데이터를 보낼 서버 주소를 적는다.

```html
<form method="get" action="server">
```

## 실습: form 값으로 화면 바꾸기

form에서 받은 값을 id로 찾아 스크립트에서 동적으로 적용해 봤다. `select`와 `input`의 `onchange` 속성을 썼다.

- 요금 납부 방법에서 "안낼래요"를 고르면 경고 창
- 색상을 고르면 기종 선택 영역의 배경색이 그 색으로 바뀜

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>개통 신청서</title>
<style>
  body {
    width: 300px;
    font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
    background-color: #f4f4f4;
    color: #333; /* 기본 글씨 색상 */
    line-height: 1.6;
    padding: 20px;
  }
  div {
    width: 90%;
    max-width: 800px;
    margin: auto;
    background: #fff;
    padding: 20px;
    box-shadow: 0 0 10px rgba(0, 0, 0, 0.3);
  }
  #personal {
    border: 1px solid #ddd;
    font-weight: bold;
    background-image: url("img/back1.jpeg");
  }
  #select {
    background-color: #f2f2f2;
    color: #333;
  }
  input[type="submit"] {
    background-color: #4CAF50;
    border: none;
    color: white;
    padding: 10px 20px;
    font-size: 16px;
    cursor: pointer;
  }
</style>
</head>
<body>
<form>
  <div id="personal">
    <p>이름 : <input type="text" name="usrname" id="usrname" maxlength="5"></p>
    <p>생년월일 : <input type="date" name="date" id="date"></p>
    <p>주소<br>
      우편번호 : <input type="search" name="zipcode" id="zipcode"><br>
      시/도 : <input type="text" name="address1" id="address1" maxlength="10"><br>
      읍/면/동 : <input type="text" name="address2" id="address2" maxlength="20"><br>
      나머지 주소 : <input type="text" name="address3" id="address3" maxlength="20">
    </p>
    <p>요금 납부 방법 :
      <select name="payment" id="payment" onchange="check()">
        <option value="bank">계좌자동이체</option>
        <option value="credit_c">신용카드</option>
        <option value="check_c">체크카드</option>
        <option value="warn">안낼래요</option>
      </select>
    </p>
    <p>연락처 : <input type="tel" name="tel" id="tel"></p>
    <p>변경 신청 날짜 : <input type="datetime-local" name="changeDate" id="changeDate"></p>
  </div>

  <div id="select">
    <p>기종 선택 :
      <select name="device" id="device">
        <optgroup label="삼성">
          <option>Galaxy S24</option>
          <option>Galaxy S24+</option>
          <option>Galaxy S24 Ultra</option>
          <option>Galaxy S23</option>
          <option>Galaxy S23+</option>
          <option>Galaxy S23 Ultra</option>
        </optgroup>
        <optgroup label="애플">
          <option>iPhone 15</option>
          <option>iPhone 15 Pro</option>
          <option>iPhone 15 Pro Max</option>
          <option>iPhone 14</option>
          <option>iPhone 14 Pro</option>
          <option>iPhone 14 Pro Max</option>
        </optgroup>
      </select>
    </p>
    <p>요금제 선택 :
      <select name="feetype" id="feetype">
        <option value="55000">제일 저렴한 요금제</option>
        <option value="88000">중간 요금제</option>
        <option value="100000">데이터 무제한 요금제</option>
      </select>
    </p>
    <p>색상 선택 : <input type="color" name="deviceColor" id="deviceColor" onchange="changeBack()"></p>
  </div>

  <div id="final">
    <p><input type="submit" value="제출하기"></p>
  </div>
</form>

<script>
  function check() {
    var pay = document.getElementById("payment").value;
    if (pay == "warn") {
      alert("다시 생각해 보세요!");
    }
  }
  function changeBack() {
    var color = document.getElementById("deviceColor").value;
    var select = document.getElementById("select");
    select.style.backgroundColor = color;
  }
</script>
</body>
</html>
```
