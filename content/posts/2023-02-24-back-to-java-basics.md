## 1. 프로그래밍과 자바

### 프로그래밍이란?

- **프로그래밍(programming)**: 컴퓨터 프로그램을 만드는 일
- **프로그래머(programmer)**: 프로그램을 만드는 사람
- **프로그램(program)**: 컴퓨터에게 일을 시키는 명령의 집합
- **컴파일(compile)**: 사람이 만든 프로그램이 문법에 맞는지 확인하고, 컴퓨터가 이해할 수 있는 언어로 번역하는 작업
- **컴파일러(compiler)**: 컴파일 작업을 하는 프로그램

사람이 프로그래밍 언어(고급 언어)로 프로그램을 만들면, 컴파일러가 그 소스 코드를 컴퓨터 언어(저급 언어)로 번역하고, 그다음 실행된다. 사람이 이해하기 쉬울수록 고급 언어, 컴퓨터가 이해하기 쉬울수록 저급 언어다. 저급 언어의 예로는 어셈블리어가 있다.

### 왜 자바를 많이 쓸까?

자바는 1991년 제임스 고슬링이 썬 마이크로시스템즈에서 개발한 언어다. 슬로건은 "Write once, run anywhere", 한 번 작성하면 어디서든 돌아간다는 뜻이다. 플랫폼에 종속되지 않아서 여러 플랫폼에서 실행할 수 있다.

!!!세상에 이게 몬소리에용???

C 언어와 비교해 보자. `test.c`를 윈도우와 리눅스 두 운영체제에서 실행해야 한다면, 윈도우용(컴파일러, 실행 파일, 윈도우 환경)과 리눅스용(컴파일러, 실행 파일, 리눅스 환경)을 운영체제마다 새로 만들어야 한다.

자바는 자바 가상 머신(JVM)을 통해 실행된다. 소스 코드를 실행하면 JVM이 먼저 받아서, 지금 실행 중인 운영체제에 맞게 바꿔 실행해 준다. JVM은 자바를 설치할 때 자동으로 깔린다.

```text
test2.java → 자바 컴파일러 → 바이트 코드 test2.class → 윈도우 JVM 또는 리눅스 JVM → 실행
```

자바의 다른 특징도 정리해 보면 이렇다.

- **객체 지향 언어**: 소스 코드를 실행 순서대로 작성하지 않고 '객체' 단위로 프로그래밍하며, 객체 사이의 관계를 이용해 프로그램을 만든다. 그래서 유지보수가 편하고 확장성이 좋다.
- **안정적**: C나 C++의 포인터를 쓰지 않는다. 메모리를 직접 제어하지 않으니 포인터 때문에 생기는 오류 위험이 없다. 또 가비지 컬렉터가 주기적으로 메모리를 수거해서 메모리를 효율적으로 관리한다.
- **오픈소스**: 기본 기능을 직접 개발하지 않고 JDK(자바 개발 키트)를 이용해 개발할 수 있다. 자료구조, 네트워크, 입출력, 예외 처리 등에 최적화된 라이브러리를 쓸 수 있다.

자바로는 웹 서버, 안드로이드 앱, 게임 등을 만들 수 있다.

## 2. 자바 개발 환경 설치하기

### 자바 설치

<https://www.oracle.com/kr/java/technologies/downloads/>에서 받는다. 자바 17이 LTS(Long Term Support) 버전이라서 17을 받았다.

**윈도우에 설치한다면**

1. 설치 확인: 프로그램을 내려받은 폴더 안의 `bin` 폴더에서 Shift + 우클릭 → PowerShell 열기 → `.\java.exe -version`
2. 환경 변수 설정: 내 PC → 속성 → 고급 시스템 설정 → 환경 변수
    - 시스템 변수 → 새로 만들기 → 변수 이름 `JAVA_HOME`, 값은 JDK를 설치한 폴더(예: `D:\내폴더\jdk-17...`)
    - `Path`에 `%JAVA_HOME%\bin` 추가

**맥에 설치한다면**

내 기억으로는 따로 할 일 없이, M1 맥은 aarch64용 파일, 인텔 맥은 x64용 파일을 받아서 설치하면 끝이었다.

### 이클립스 설치

자바로 개발하려면 통합 개발 환경(IDE)을 설치해야 한다. 메모장으로 코딩할 수도 있고, 무료 툴인 이클립스, 유료 툴인 인텔리제이, 웹에서 코딩할 수 있는 사이트도 있다. 공부하는 입장에서는 가장 많이 쓰는 이클립스가 무난하다. 책에서도 당연하다는 듯 이클립스로 알려 준다.

[eclipse.org](https://www.eclipse.org)에서 운영체제에 맞는 **Eclipse IDE for Java Developers**를 받아 실행하면 된다.

### 워크스페이스 구조

```text
workspace > project > package  > class (영문 + 숫자)
개발자      사이트     공지사항     글쓰기
```

새 프로젝트는 File → New → Project → Java Project에서 만든다.
