## 1. 인터넷과 웹

- **인터넷**: 전 세계를 잇는 통신망
- **웹**: 인터넷을 쓸 수 있게 해 주는 도구. 팀 버너스리가 발표한 World Wide Web(WWW)
- **W3C**: 국제 웹 표준화 단체. HTML 표준을 만든다. HTML5는 2014년 10월에 표준이 됐다.
- **실행 환경**(클라이언트 프로그램): Chrome, Edge, Safari, Firefox, Opera
- **개발 환경**: 이클립스, Tomcat, 자바 개발 도구

## 2. 웹은 어떻게 동작할까

웹은 **요청과 응답**으로 동작한다.

**요청**: 무언가를 요구하는 쪽, 클라이언트(사용자)

- 클라이언트 프로그램은 프런트엔드 프로그램이라고도 하며, 사용자와 가깝고 클라이언트 쪽에서 실행된다.
- **HTML**로 요소를 만들고(구조), **CSS**로 디자인하고(효과), **JavaScript**로 프로그래밍한다.
- JavaScript는 클라이언트 웹 개발용으로 만들어졌지만 지금은 서버 개발, 로봇 개발에도 쓰인다.

**응답**: 요구에 대한 대답을 돌려주는 쪽, 서버(제공자)

- 서버 프로그램은 백엔드라고도 하며, 서버에서 실행되고 사용자와는 멀다.
- 클라이언트 요청에 따라 알맞은 파일과 데이터를 준다.
- 웹 프레임워크, **MVC 프레임워크**, 비동기 프레임워크를 활용한다.

웹은 요청과 응답이 오가는 통로 역할을 한다.

- 서버는 항상 요청을 기다리는(listening) 상태여야 한다.
- **URL**: 웹에서 어떤 대상을 구분하는 주소
- **서버**: 서비스를 하는 주체

## 3. 웹 표준

### HTML5: 웹 페이지 구성

- **마크업(markup)**: 웹 페이지의 서식이나 구조를 표현하는 정보
- **멀티미디어**: 플러그인 없이 음악·동영상 재생
- **그래픽**: 하드웨어 가속으로 2D, 3D 그래픽 구현
- **통신**: 서버와 소켓 통신 가능(쌍방향 통신), 실시간 채팅
- **장치 접근**
- **오프라인과 저장소**
- **시맨틱 웹**: 검색 엔진이 알아서 자료를 분석하는 지능형 웹

## 정리

- **요소**: HTML 페이지를 구성하는 각 부품
- **태그**: 요소를 만들 때 쓰는 작성 방법
- 내용을 가질 수 있는 요소를 만들 때 앞에 붙이는 태그를 **시작 태그**, 뒤에 붙이는 태그를 **끝 태그**라고 한다.
- **속성**: 태그에 추가 정보를 줄 때 쓴다.
- **주석**: 실행에는 영향을 주지 않고 설명용으로 쓰는 코드
- 내부 스타일: HTML 페이지 안에서 `<style>` 태그로 스타일 시트를 직접 입력
- 외부 스타일 시트를 불러오려면 `<link>` 태그를 쓴다.
- 외부 자바스크립트를 불러오려면 `<script>` 태그를 쓴다. 외부 자바스크립트 파일의 확장자는 `.js`다.

### head: 데이터를 가진 영역

body에 필요한 스타일 시트와 자바스크립트도 여기서 제공한다.

- `meta`: 웹 페이지에 추가 정보 전달
- `title`: 문서 제목
- `script`: 자바스크립트
- `link`: 다른 파일(CSS 등)을 웹 페이지에 추가. 외부 스타일은 `link`의 `href`로 불러온다.
- `style`: 내부 스타일. `style` 태그로 스타일 시트를 직접 입력
- `base`: 문서 안 상대 경로의 기준 URL
