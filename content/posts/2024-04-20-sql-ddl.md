DDL은 테이블 같은 데이터베이스 구조를 정의하는 명령어다.

## CREATE

스키마, 도메인, 테이블, 뷰, 인덱스, 시퀀스 등을 정의한다.

```sql
CREATE TABLE 테이블이름 (
    속성이름 데이터타입 [DEFAULT 기본값] [NOT NULL], ...
    [, PRIMARY KEY (기본키속성, ...)]
    [, UNIQUE (대체키속성, ...)]
    [, FOREIGN KEY (외래키속성, ...)
         REFERENCES 참조테이블(기본키속성, ...)
         [ON DELETE 옵션]
         [ON UPDATE 옵션]]
    [, CONSTRAINT 제약조건이름] [CHECK (조건식)]
);

CREATE VIEW 뷰이름 [(속성이름[, 속성이름, ...])] AS SELECT문;

CREATE [UNIQUE] INDEX 인덱스이름
    ON 테이블이름 (속성이름 [ASC | DESC] [, 속성이름 [ASC | DESC]]);
```

## ALTER

테이블 정의를 바꿀 때 쓴다.

```sql
ALTER TABLE 테이블이름
    [ADD 속성이름 데이터타입]
    [DROP COLUMN 속성이름]
    [ALTER COLUMN 속성이름 데이터타입]
    [ALTER COLUMN 속성이름 [NULL | NOT NULL]]
    [ADD PRIMARY KEY (속성이름)];
```

## DROP

스키마, 도메인, 테이블, 뷰, 인덱스를 삭제한다. DROP은 테이블(또는 스키마, 뷰 등) **전체**를 지우는 문법이니 주의하자.

```sql
DROP TABLE 테이블이름;
```

## 주요 제약 조건

- **PRIMARY KEY**: 기본키로 쓸 속성을 지정
- **UNIQUE**: 대체키로 쓸 속성을 지정. 중복된 값을 가질 수 없다.
    - `CREATE UNIQUE INDEX`: 중복 값이 없는 속성으로 인덱스 생성
    - `CREATE INDEX`: 중복 값을 허용하는 속성으로 인덱스 생성
- **FOREIGN KEY ~ REFERENCES ~**: 외래키로 쓸 속성을 지정
    - `ON DELETE`: 참조 테이블의 튜플이 삭제됐을 때 기본 테이블이 취할 동작
    - `ON UPDATE`: 참조 테이블의 튜플이 변경됐을 때 기본 테이블이 취할 동작
- **CONSTRAINT**: 제약 조건에 이름을 붙임
- **CHECK**: 값에 대한 제약 조건을 정의

## 사용자 추가하기

CREATE와 GRANT를 같이 쓴다.

```sql
CREATE USER 사용자이름 IDENTIFIED BY 비밀번호;
GRANT RESOURCE, CONNECT, CREATE VIEW TO 사용자이름;
```
