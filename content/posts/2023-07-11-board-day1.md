## 마리아디비 설치

1. 터미널에서 `brew help`로 brew가 설치돼 있는지 확인 (예전에 설치해 뒀음)
2. 마리아디비 설치: `brew install mariadb`
3. 설치 확인 후 시작: `brew services start mariadb`

![](/images/posts/board-day1/01.png)

4. mysql 접속: `sudo mysql -u root -p`
5. PC 비밀번호로 입장~!
6. `set password=password('비밀번호');`로 비밀번호 바꾸기

![](/images/posts/board-day1/02.png)

7. node 설치: `brew install node`

## 데이터베이스와 유저 만들기

- test_board 데이터베이스 생성: `create database test_board;`

![](/images/posts/board-day1/03.png)

- 유저 생성: `grant all on test_board.* to M_board@localhost identified by '비밀번호';`
    - 형식: `grant all on [데이터베이스].* to [유저이름]@[접속호스트] identified by '[비밀번호]';`
- 유저 확인: `select host, user, password from mysql.user;`
    - M_board가 생긴 걸 확인!

![](/images/posts/board-day1/04.png)

## 테이블 만들기

`use test_board;` 후에 테이블을 만든다.

![](/images/posts/board-day1/05.png)

```sql
create table BOARD
    -> (NUM NUMBER(9) NOT NULL,
    -> NAME VARCHAR2(20) NOT NULL,
    -> PWD VARCHAR2(10) NOT NULL,
    -> EMAIL VARCHAR2(50),
    -> SUBJECT VARCHAR2(50) NOT NULL,
    -> CONTENT VARCHAR2(4000) NOT NULL,
    -> IPADDR VARCHAR2(20),
    -> HITCOUNT NUMBER(9),
    -> CREATED DATE,
    -> CONSTRAINT PK_BOARD_NUM PRIMARY KEY(NUM));
```
