이번 글에서는 Vue 3와 Pinia로 **프로젝트 목록을 부모-자식 형태로 그룹화**하고, 화면에서 필요할 때 펼치거나 접을 수 있게 만든 경험을 정리해 보려 한다.

## 1. 프로젝트 그룹의 기본 개념

내가 만든 구조에서 group은 **템플릿에서 반복하며 프로젝트 묶음을 관리하는 단위**다.

그룹 하나에는 부모 프로젝트, 자식 프로젝트 목록, 자식 목록이 열려 있는지 여부가 들어 있다. 즉, **부모-자식 계층 구조를 화면에 깔끔하게 표현**하려고 만든 구조다.

덕분에 커스텀 프로젝트와 독립 프로젝트를 한 화면에서 똑같이 다룰 수 있었고, 사용자가 원하는 프로젝트만 펼쳐서 볼 수 있게 됐다.

```text
커스텀 프로젝트 Alpha (부모, isOpen: false)
|--- 프로젝트 Alpha-1 (자식)
|--- 프로젝트 Alpha-2 (자식)
|--- 프로젝트 Alpha-3 (자식)
커스텀 프로젝트 Beta (부모, isOpen: true)
|--- 프로젝트 Beta-1 (자식)
|--- 프로젝트 Beta-2 (자식)
단독 프로젝트 Gamma (부모, isOpen: false)
단독 프로젝트 Delta (부모, isOpen: false)
```

## 2. 그룹화 로직

### 이전 펼침 상태 보존

처음 구현하면서 가장 신경 쓴 부분은 **데이터를 새로 받아와도 사용자가 펼쳐 둔 상태를 유지**하는 것이었다. 그래서 이전 그룹들의 열림/닫힘 상태를 따로 저장해 두고, 새로 그룹화할 때 그 값을 다시 반영했다.

이렇게 하니 서버에서 데이터를 다시 받아와도 사용자가 펼쳐 놓은 프로젝트 목록이 그대로 남아 있었다.

### 부모-자식 프로젝트 구분

그룹화의 핵심은 **ID 규칙으로 부모와 자식을 구분**하는 것이었다. 부모 프로젝트는 특정 패턴의 ID로 판단하고, 자식 프로젝트는 부모 ID 패턴과 맞춰서 연결했다.

이 과정을 거치면 각 부모 아래에 자식들이 정확히 배치돼서, 트리 구조를 보는 느낌 그대로 화면에 옮길 수 있었다.

### 독립 프로젝트 처리

커스텀 프로젝트에 속하지 않는 프로젝트는 별도의 그룹으로 처리했다.

부모가 없는 독립 프로젝트도 하나의 그룹으로 다뤄서, 화면에서는 커스텀 프로젝트와 똑같이 펼치거나 클릭할 수 있다.

## 3. 화면 렌더링

부모 프로젝트는 목록에 항상 보이게 하고, 옆에 토글 아이콘을 둬서 클릭하면 자식 목록이 열리고 닫히게 했다.

자식 프로젝트는 부모가 열려 있을 때만 렌더링한다. 덕분에 화면이 깔끔하고, 필요 없는 정보가 한꺼번에 쏟아지지 않는다.

## 4. 상태 관리에서 신경 쓴 점

상태 관리에서 중요했던 건 **Vue의 반응성이 확실하게 동작하게 하는 것**이었다.

Vue 3는 배열 요소를 직접 바꿔도 대부분 반응하지만, 그룹 목록을 매번 계산해서 다시 만드는 구조에서는 배열 일부를 고치는 것보다 **배열 전체를 새로 만들어 할당**하는 쪽이 상태 흐름이 분명했다.

이렇게 하면 그룹의 열림/닫힘 상태를 안전하게 바꿀 수 있고, 다른 컴포넌트에서도 같은 상태를 일관되게 공유할 수 있다.

## 5. 실시간 상태 반영 (k8s 연동)

5초마다 서버에서 Pod 상태를 가져와 프로젝트 목록에 반영했다. 여기서도 값만 바꾸지 않고 **새 배열로 교체**했더니 반응성이 정확하게 동작해서 화면이 실시간으로 갱신됐다.

덕분에 사용자는 항상 최신 상태를 볼 수 있었고, 실시간 모니터링 화면으로서도 안정적으로 동작했다.

## 6. 느낀 점

- **ID 규칙을 활용하니 그룹화가 깔끔해졌다.** 리스트를 그냥 나열하는 대신 ID 패턴으로 트리 구조를 명확하게 표현할 수 있었다.
- **새 배열 할당 방식이 안전하다.** 기존 배열의 값만 바꾸는 것보다 새 배열로 할당하는 쪽이 훨씬 예측 가능했다.
- **그룹화 로직과 화면을 분리했다.** 그룹화는 스토어에서, 렌더링은 컴포넌트에서 하니 컴포넌트 코드가 훨씬 단순해졌다.
- **사용자 경험이 좋아졌다.** 펼침 상태 유지, 실시간 상태 반영, 독립 프로젝트 포함까지 하니 프로젝트 상황을 한눈에 파악할 수 있었다.

## 마무리

이 구조 덕분에 **관련 프로젝트들을 한눈에 그룹으로 관리**하고, 필요할 때 펼치거나 접어서 보는 화면을 만들 수 있었다.

Vue + Pinia로 그룹화를 구현하면서 얻은 가장 큰 교훈은, **상태 관리와 반응성 처리에 세심하게 신경 쓰면 작은 코드 변화만으로도 안정적이고 직관적인 화면을 만들 수 있다**는 점이다.
