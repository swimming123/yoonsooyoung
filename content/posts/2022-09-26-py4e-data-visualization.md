## 데이터 검색과 시각화

먼저 데이터 검색과 시각화 강의를 들었다.

**데이터 분석**

- 데이터를 쓰기 전에, 프로그램에서 쓸 수 있도록 가공해야 한다.
- 데이터가 엄청 크다면 '데이터 마이닝' 관점에서 빅데이터를 처리한다.
- 이 과정은 데이터 마이닝, 데이터 분석, 자연어 처리 등으로 더 나눌 수 있다.

강의 예제는 구글 JSON API로 지오데이터를 쓰는 개인 데이터 마이닝이었다.

![](/images/posts/py4e-data-visualization/02.png)

흐름은 이렇다.

1. 구글에서 데이터를 가져온다.
2. `where.data`는 위치 정보(지역 이름, 학교 이름 등)를 담아 두는 큐다.
3. `geoload.py`가 그 위치가 `geodata.sqlite` 데이터베이스에 이미 있는지 확인한다.
4. 이걸 반복하면서, 없는 데이터는 데이터베이스에 추가한다.
5. `geodump.py`는 `geodata.sqlite`에서 데이터를 읽어 정리된 정보를 출력하고, 다음에 무엇을 하면 되는지 알려 준다.
6. 마지막으로 구글 API를 쓰는 자바스크립트 코드를 실행하면, 구글 지도를 활용한 검색 화면이 된다.

여기까지가 1강이고, 다음은 실습 해설 강의인 것 같다. 그런데! 나는 자바스크립트를 모른다 ㅜㅜ 그래서 오늘은 예전에 공부했던 데이터 분석 내용을 다시 공부해 봤다.

## scikit-learn으로 회귀 분석

오늘 쓴 scikit-learn(사이킷런)은 파이썬의 대표적인 머신러닝 라이브러리다. 오픈소스로 공개되어 있고 많은 사람이 써서 정보를 찾기 쉽다. 공부하기 좋은 라이브러리라고 생각한다.

회귀 분석은 주어진 데이터를 바탕으로 값을 예측하는 분석이다. 지도 학습으로 회귀 문제를 푸는 알고리즘이라고도 한다. 데이터 규모와 특성에 따라 추천하는 방법이 다르다.

| 방법 | 언제 쓰나 |
| --- | --- |
| SGD(stochastic gradient descent) | 대규모 데이터(10만 건 이상)일 때 추천하는 선형 회귀 |
| LASSO, ElasticNet | 중소 규모(10만 건 미만)이고, 설명 변수 중 일부만 중요할 때 |
| Ridge, Linear SVR | 중소 규모(10만 건 미만)이고, 설명 변수 전부가 중요할 때 |
| SVR(가우스 커널), 앙상블 | Ridge나 Linear SVR로 잘 안 될 때 쓰는 비선형 회귀 |

설명 변수는 결과에 영향을 주는 원인이 되는 변수를 말한다.

### 결측치 채우기

> scikit-learn으로 결측 데이터를 '다른 데이터에서 대표값을 찾아 채우는 방법'으로 처리해 보세요.

```python
import seaborn as sns
from sklearn.impute import SimpleImputer
import pandas as pd

df = sns.load_dataset('titanic')
df.tail()
```

![위 코드를 실행하면 나오는 표](/images/posts/py4e-data-visualization/03.png)

888번 행의 `age`, `deck`에 결측 데이터가 있다. 그래서 다른 데이터에서 가장 많이 나온 값(최빈값)을 찾아 채워 준다.

```python
imputer_mode = SimpleImputer(strategy="most_frequent")
df = pd.DataFrame(imputer_mode.fit_transform(df), columns=df.columns)
df.tail()
```

![데이터가 모두 채워졌다!](/images/posts/py4e-data-visualization/04.png)
