## 1. 컴퓨터는 데이터를 어떻게 표현할까?

ON과 OFF, 즉 1과 0으로 표현한다.

사람은 주로 10진수로 숫자를 표현한다. 0부터 9까지 세다가 10이 되는 순간 자릿수를 올린다. 10진수를 2진수로 바꾸려면 2로 나누고, 나누고, 또 나누고...

컴퓨터는 2진수밖에 이해하지 못하기 때문에 문자도 2진수로 바꿔야 한다. **아스키 코드**는 숫자, 문자, 특수 기호 등을 8비트 값으로 미리 정해 둔 규칙이다. 엄청 많은데, 이 세 개는 알아 두면 좋다.

| 문자 | 아스키 코드 |
| --- | --- |
| `0` | 48 |
| `A` | 65 |
| `a` | 97 |

**부호 비트**: 음수는 2진수로 어떻게 표현할까? 맨 앞 비트를 부호 비트로 정해서, 0이면 양수, 1이면 음수로 쓴다.

## 2. 변수란?

변하는 수.

```java
int age;
age = 100;
```

`int`는 변수의 자료형(정수), `age`는 변수 이름, `age = 100`은 변수에 100을 대입한다는 뜻이다.

```java
int age = 100;
```

이렇게 쓰면 변수를 선언하면서 동시에 값을 대입해 초기화한다. 변수를 쓰는 상황에 따라 선언과 동시에 초기화할지, 나중에 초기화할지가 달라진다.

**변수 이름 규칙**

- 영문 대소문자, 숫자, 특수 문자 `$`, `_`만 쓸 수 있다.
- 숫자로 시작할 수 없다.
- 자바 예약어는 쓸 수 없다.

## 3. 자료형: 변수가 저장되는 공간의 특성

자료형에는 기본 자료형과 참조 자료형이 있다. 기본 자료형은 자바가 기본으로 제공하고, 메모리를 얼마나 쓸지 정해져 있다.

| 크기 | 정수형 | 문자형 | 실수형 | 논리형 |
| --- | --- | --- | --- | --- |
| 1바이트 | byte | | | boolean |
| 2바이트 | short | char | | |
| 4바이트 | int | | float | |
| 8바이트 | long | | double | |

`String`(문자열)은 기본 자료형이 아니다.

## 4. 상수와 리터럴

- **상수**: 변하지 않는 값
- **리터럴**: 프로그램에서 쓰는 모든 숫자, 문자, 논리값

## 5. 형 변환

연산을 하기 전에 자료형을 하나로 맞추는 과정이다.

기본 원칙

1. 바이트 크기가 작은 자료형에서 큰 자료형으로는 자동으로 바뀐다.
2. 덜 정밀한 자료형에서 더 정밀한 자료형으로는 자동으로 바뀐다.

### 묵시적 형 변환(자동 형 변환)

```java
// 바이트 크기가 작은 자료형 → 큰 자료형
byte bNum = 10;
int iNum = bNum;      // byte 값을 int로

// 덜 정밀한 자료형 → 더 정밀한 자료형
int iNum2 = 20;
float fNum = iNum2;   // 정수를 실수로

// 연산 중 자동 변환
int iNum3 = 20;
float fNum2 = iNum3;
double dNum;
dNum = fNum2 + iNum3; // float 결과가 double로 바뀌어 대입됨
```

### 명시적 형 변환(강제 형 변환)

강제로 자료형을 바꾸려면 괄호 안에 바꿀 자료형을 적는다.

```java
// 바이트 크기가 큰 자료형 → 작은 자료형
int iNum = 10;
byte bNum = (byte) iNum;

// 더 정밀한 자료형 → 덜 정밀한 자료형
double dNum = 3.14;
int iNum2 = (int) dNum;  // 3
```

연산 중에도 괄호로 자료형을 적어 형 변환할 수 있다.

## 6. 연산자

### 항의 개수에 따라

| 연산자 | 설명 | 예 |
| --- | --- | --- |
| 단항 연산자 | 항이 한 개 | `++sum` |
| 이항 연산자 | 항이 두 개 | `a + b` |
| 삼항 연산자 | 항이 세 개 | `(5 > 3) ? true : false` |

### 대입 연산자

`=`를 기준으로 오른쪽 값을 왼쪽 변수에 대입한다. 예: `int sum = 100;`

### 부호 연산자

- `+`: 값을 양수로 (`+1`)
- `-`: 값을 음수로 (`-1`)

### 산술 연산자

| 연산자 | 기능 | 예 |
| --- | --- | --- |
| `+` | 두 항을 더함 | `5 + 3` |
| `-` | 앞 항에서 뒤 항을 뺌 | `5 - 3` |
| `*` | 두 항을 곱함 | `5 * 3` |
| `/` | 앞 항을 뒤 항으로 나눈 몫 | `5 / 3` → 1 |
| `%` | 앞 항을 뒤 항으로 나눈 나머지 | `5 % 3` → 2 |

### 증가·감소 연산자

| 예 | 동작 |
| --- | --- |
| `a = ++num;` | num에 1을 더한 뒤 a에 대입 |
| `a = num++;` | num을 a에 대입한 뒤 num에 1을 더함 |
| `a = --num;` | num에서 1을 뺀 뒤 a에 대입 |
| `a = num--;` | num을 a에 대입한 뒤 num에서 1을 뺌 |

### 관계 연산자

`a = 10`일 때

| 연산자 | 기능 | 예 |
| --- | --- | --- |
| `>` | 왼쪽이 크면 true | `a > 3` → true |
| `<` | 왼쪽이 작으면 true | `a < 3` → false |
| `>=` | 왼쪽이 크거나 같으면 true | `a >= 3` → true |
| `<=` | 왼쪽이 작거나 같으면 true | `a <= 3` → false |
| `==` | 두 값이 같으면 true | `a == 10` → true |
| `!=` | 두 값이 다르면 true | `a != 10` → false |

### 논리 연산자

| 연산자 | 기능 | 예 |
| --- | --- | --- |
| `&&` | 두 항이 모두 참이면 true, 하나라도 거짓이면 false | `(3 > 2) && (3 > 1)` → true |
| `\|\|` | 두 항 중 하나라도 참이면 true | `(3 > 2) \|\| (3 > 5)` → true |
